# CONTROLS (proposed defaults; remap in settings)
- Controllers: trigger/pinch = select; thumbstick = snap turn (30 degrees); smooth turn opt-in; menu button = panel; left-handed swap in Accessibility.
- Hands: pinch to select, poke buttons. Gaze fallback: dwell select (can be disabled; no eye data stored).
- Teacher panel: Pause, Resume, Reset, Jump to lesson, Replay, Labels, Parameters, Compare, Quiz.
- Always available: Recenter, Return to Safe Distance (fade).
- Modes: Seated / Standing.
